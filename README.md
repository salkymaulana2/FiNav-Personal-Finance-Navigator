# FinNav: Personal Finance Navigator 🚀

A generative AI wealth architecture and automated financial audit dashboard driven by Gemini 3.5 Flash.

## 🔗 Live Demo
You can try the live application here: [https://salkymaulana-finav-personalfinancenavigator.hf.space](https://salkymaulana-finav-personalfinancenavigator.hf.space)

## 🛠️ Tech Stack
- **Framework:** Streamlit (Python)
- **AI Engine:** Google Gemini 3.5 Flash API
- **Data Core:** SessionState Cache Memory
- **Visualization:** Matplotlib Graphic Library
